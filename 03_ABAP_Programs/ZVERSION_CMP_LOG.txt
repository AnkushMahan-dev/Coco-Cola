================================================================================
 Transparent table  ZVERSION_CMP_LOG   (create in SE11 before activating the
 report ZVERSION_COMPARE - the report writes one row per compared object)
================================================================================

 SE11 -> Database table -> ZVERSION_CMP_LOG
 Delivery Class : A (Application table, master & transaction data)
 Data Browser/Table View Maint. : Display/Maintenance Allowed

 Technical settings (Goto -> Technical settings):
   Data class      : APPL1  (transaction data)
   Size category   : 1 (adjust to expected volume)
   Buffering       : not allowed (log table)

--------------------------------------------------------------------------------
 Notes
--------------------------------------------------------------------------------
 - For fields typed as a raw length (CHAR10, CHAR3, CHAR100) you can either use
   the predefined data elements CHAR10 / CHAR3 / CHAR100 (they exist in standard
   ECC) or create a domain/data element. The report work area uses the table
   structure directly, so the field NAMES must match exactly.
 - The report fills LOGID with FUNCTION 'GUID_CREATE' (EV_GUID_32), so one row
   per (run, object) is always unique - INSERT ... ACCEPTING DUPLICATE KEYS.
 - Activate this table BEFORE activating ZVERSION_COMPARE, otherwise the report
   will not compile (it references the table type directly).
